# ThatDataPurple for Samsung Galaxy
The That Data Person brand colours for Samsung Galaxy phones, sized for the Galaxy S24 Ultra, by That Data Person Limited.

The wallpaper is generated by `build/build.py` from [`palette/palette.json`](../palette/palette.json).

<img src="ThatDataPurple.S24Ultra.jpg" alt="ThatDataPurple phone wallpaper" width="240">

One UI themes can only be installed from the Galaxy Themes store, so there's no theme file here. Instead, set the wallpaper and build the rest yourself in Theme Park, using the colours below.

## 1. Wallpaper and colour palette
1. Copy [`ThatDataPurple.S24Ultra.jpg`](ThatDataPurple.S24Ultra.jpg) (1440x3120, the S24 Ultra's full resolution) to the phone.
2. Open it in Gallery, then *More > Set as wallpaper*, and pick *Lock and home screens*.
3. Under *Settings > Wallpaper and style > Colour palette*, choose one of the purple palettes taken from the wallpaper.
4. Under *Settings > Display*, choose *Dark*.

That alone recolours the quick panel, settings and Samsung's own apps in purples close to the brand ones.

## 2. Theme Park (optional, for exact colours)
Theme Park is a Good Lock module from Samsung. Install Good Lock from the Galaxy Store, then add Theme Park from inside Good Lock.

- **Theme:** *Theme > Create new*, pick the ThatDataPurple wallpaper, then edit the colours to the values below and apply it.
- **Keyboard:** *Keyboard > Create new*, then set the background, keys and key text to the values below. It becomes a Samsung Keyboard theme.
- **Quick panel:** the theme colours above carry through to it. Set the background to brand dark and the active toggles to brand purple if you want to change them separately.

| Use | Colour |
|---|---|
| Background | `#0D0629` (brand dark) |
| Cards, keys, panels | `#1B1048` |
| Accent, active toggles, pressed keys | `#4320CC` (brand purple) |
| Highlights, icons | `#9580E6` (light purple) |
| Text | `#ECE8FA` |
| Text on brand purple | `#FFFFFF` |

These pairs meet WCAG AA (4.5:1): text on the background, cards and keys, and white on brand purple.
