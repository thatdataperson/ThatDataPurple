# ThatDataPurple for Windows
The That Data Person brand colours for Windows 11 and Windows Terminal, by That Data Person Limited.

Everything in this folder is generated by `build/build.py` from [`palette/palette.json`](../palette/palette.json).

![ThatDataPurple wallpaper](theme/DesktopBackground/ThatDataPurple.jpg)

## Windows 11 theme
[`bin/Release/ThatDataPurple.deskthemepack`](bin/Release/ThatDataPurple.deskthemepack) sets:

- the brand wallpaper above (3840x2160, cropped to fill)
- brand purple `#4320CC` as the accent colour
- Dark mode for both Windows and apps

Download it and double-click it. Windows installs it under *Settings > Personalization > Themes*. It may not switch to it straight away, so select the *ThatDataPurple* thumbnail there to apply it. To also colour the Start menu, taskbar and title bars, turn on *Show accent colour on Start and taskbar* and *Show accent colour on title bars and window borders* under *Settings > Personalization > Colours*. A theme file can't set those two switches.

To go back, pick another theme under *Settings > Personalization > Themes*. You can delete ThatDataPurple from there with right-click.

Windows has no full colour-theme format, so this is as far as a theme pack goes. Custom contrast themes and patched `.msstyles` files can recolour more, but they aren't suitable to ship.

## Windows Terminal
[`terminal/ThatDataPurple.json`](terminal/ThatDataPurple.json) is a colour scheme. The background matches the ThatDataPurple editor themes (`#120A33`). Every ANSI colour used as text, including bright black, meets WCAG AA (4.5:1) against both the background and the selection.

### Install the scheme
Run `terminal/install.ps1`. It copies the scheme into Terminal's fragments folder (`%LOCALAPPDATA%\Microsoft\Windows Terminal\Fragments\ThatDataPurple`). Then restart Terminal and choose **ThatDataPurple** under *Settings > Profiles > Defaults > Appearance > Color scheme*.

Or open *Settings > Open JSON file* and paste the scheme object into `"schemes"`.

### Tab bar (optional)
Fragments can't hold Terminal themes. For the dark tab row, paste [`terminal/theme.json`](terminal/theme.json) into the `"themes"` list in `settings.json`, and set `"theme": "ThatDataPurple"`.
