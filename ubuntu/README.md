# ThatDataPurple for Ubuntu
The That Data Person brand colours for Ubuntu's GNOME desktop and its Ptyxis terminal, by That Data Person Limited.

Everything in this folder except the two scripts is generated by `build/build.py` from [`palette/palette.json`](../palette/palette.json). The app colours need Ubuntu 24.10 or later (libadwaita 1.6+).

![ThatDataPurple wallpaper](backgrounds/ThatDataPurple.jpg)

## Install
Clone or download this repo, then run:

```
./ubuntu/install.sh
```

Run it as yourself, not with `sudo`. It sets:

- **Terminal**: adds [`terminal/ThatDataPurple.palette`](terminal/ThatDataPurple.palette) to Ptyxis and selects it in every profile. The colours match the Windows Terminal scheme, and the title bar uses brand dark `#0D0629`.
- **GNOME Terminal** (Ubuntu 25.04 and earlier): if it's installed, adds a *ThatDataPurple* profile from [`terminal/ThatDataPurple.gnome-terminal.dconf`](terminal/ThatDataPurple.gnome-terminal.dconf) and makes it the default.
- **GNOME apps**: copies [`gtk-4.0/gtk.css`](gtk-4.0/gtk.css) to `~/.config/gtk-4.0/`. Apps built with libadwaita (Files, Settings, Text Editor, Ptyxis and most GNOME apps) use the brand purples for windows, sidebars, header bars, cards, popovers and the accent. If you already had a `gtk.css`, it's kept as `gtk.css.before-thatdatapurple`.
- **Desktop**: the brand wallpaper, GNOME's purple accent and the dark style (`Yaru-purple-dark`).

Restart open apps to see the new colours. To choose the palette yourself, open Ptyxis *Preferences > Profiles > Edit > Colour Palette > ThatDataPurple*.

## Uninstall
Run `./ubuntu/uninstall.sh`. It removes the palette, the GNOME Terminal profile, `gtk.css` and the wallpaper, puts back your old `gtk.css` if there was one, and resets the Ptyxis palette and wallpaper to Ubuntu's defaults. It leaves the accent and the dark style as they are.

## What it can't colour
- **GNOME Shell** (top bar, Quick Settings, overview) only takes GNOME's own accent colours, so it uses GNOME's purple rather than brand purple. A full Shell theme needs the User Themes extension.
- **GTK 3 apps** keep Yaru's purple dark theme.
- **Ptyxis** has no selection colour setting, so selections use its default.

The text colours meet WCAG AA (4.5:1) against the backgrounds they're drawn on. See [`palette/CONTRAST.md`](../palette/CONTRAST.md).
